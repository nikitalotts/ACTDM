## Безусловная диффузионная модель и classifier guidance

В этом подходе условная генерация получается из безусловной за счет добавления к безусловной диффузионной модели градиента внешнего бинарного классификатора, оценивающего корректность продолжения. Сначала обучается безусловная диффузионная модель, а затем - классификатор, предсказывающий, является ли продолжение корректным.

Реализованы три варианта обучения классификатора, отличающиеся схемой генерации негативных примеров: на перемешанных парах (shuffled), на аугментированных парах (augmented) и на их объединении (combined).

## Зависимости

Список используемых библиотек приведен в [requirements.txt](./requirements.txt). Создать и активировать окружение можно с помощью Miniconda:
- `conda create --name actdm_guidance python=3.9`
- `conda activate actdm_guidance`
- `conda install pip`
- `pip install -r requirements.txt`
- `python -m spacy download en`

## Загрузка датасета

Скачать датасет ROCStories можно следующей командой:
```
python -m data.load --dataset_name=rocstories
```

## Подсчет статистик

Для корректного обучения диффузионной модели необходимо предварительно посчитать статистики:
```
bash make_statistic.sh
```

## Обучение декодера

Необходимо обучить декодер, восстанавливающий токены по энкодингам:
```
bash train_decoder.sh
```

## Обучение безусловной диффузионной модели

После подсчета статистик и обучения декодера можно запускать обучение безусловной диффузионной модели:
```
bash train_diffusion.sh
```

## Обучение классификатора (conditional encoder)

Затем обучается бинарный классификатор корректности продолжения. Доступно три варианта аугментации негативных примеров:
```
bash train_conditional_encoder_shuffled.sh    # обучение классификатора по схеме 1 (перемешанные пары)
bash train_conditional_encoder_augmented.sh   # обучение классификатора по схеме 2 (аугментированные пары)
bash train_conditional_encoder_combined.sh    # обучение классификатора по схеме 3 (объединение схем 1 и 2)
```

## Оценка моделей

Для генерации продолжений и подсчета метрик используйте:
```
bash eval_diffusion_uncondition.sh   # одиночный запуск безусловной генерации
bash eval_diffusion_condition.sh     # одиночный запуск условной генерации с classifier guidance
bash eval_diffusion_stat.sh          # многократный запуск для усреднения метрик и оценки разброса
```
